# 🧠 NeuroFlow

NeuroFlow is an open-source platform for functional audio designed to enhance:

- 🎯 Focus
- 😌 Relaxation
- 😴 Sleep

---

## 🚀 Repositories

- 🔧 API → https://github.com/NeuroFlow-Audio-Productivity/neuroflow-api
- 🎧 Frontend → https://github.com/NeuroFlow-Audio-Productivity/neuroflow-front

---

## 🧩 Core Features

- Binaural beats engine
- Custom audio flows (presets)
- Pomodoro / focus sessions
- Background music mixing

---

## 🛠️ Tech Stack

- Backend: Laravel
- Frontend: Vue + Vite
- Audio Engine: Web Audio API
