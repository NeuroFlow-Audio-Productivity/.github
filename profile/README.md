## 🚀 About

**NeuroFlow** is an open-source alternative to platforms like Brain.fm — built to deliver scientifically-inspired audio experiences using:

* 🎧 Binaural beats
* 🌊 Noise layers (white, pink, brown)
* 🎵 Background music mixing
* ⏱️ Focus sessions (Pomodoro / deep work)

All designed to help you enter the right mental state — on demand.

---

## 🧩 Core Features

* 🧠 **Binaural Audio Engine** — generate precise brainwave frequencies
* 🎛️ **Flows (Presets)** — customizable audio experiences
* 🎵 **Layered Audio System** — combine beats, noise, and music
* ⏱️ **Focus Sessions** — built-in timer for productivity
* 👤 **User Profiles** — save and reuse your favorite flows
